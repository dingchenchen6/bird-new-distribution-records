# Bird Scientific Data Descriptor

This task contains a full draft of a `Scientific Data`-style data descriptor for the China Bird New Record database (CBNR), prepared by integrating:

- the methods framework from `2026.4.11.docx`
- the broader scientific framing from the mammal GEB paper
- project context from the youth foundation proposal
- corrected bird new-record results generated in the repository

## Main outputs

- Source manuscript text:
  - `results/bird_scientific_data_descriptor_source.md`
- Word manuscript:
  - `results/bird_scientific_data_descriptor_scientific_data.docx`
- Builder script:
  - `code/build_scientific_data_descriptor_docx.py`

## Notes

- The current version follows the logic and section structure of a `Scientific Data` Data Descriptor:
  - Abstract
  - Background & Summary
  - Methods
  - Data Records
  - Technical Validation
  - Usage Notes
  - Code Availability
- Three tables and three figures are embedded in the DOCX draft.
- A few citation items and repository/DOI placeholders remain explicitly marked for final confirmation before submission.
